# NEURO//PATH
Структура проекта:
- `index.html` — разметка страницы (HTML5)
- `css/style.css` — стили, киберпанк (CSS3)
- `js/data.js` — данные: отрасли, навыки, профессии, хроника (JavaScript)
- `js/app.js` — логика: анализ, навыки, план, карта, график на Canvas (JavaScript)
- `calc.py` — формула риска на Python: `python calc.py --test`, `python calc.py tech senior advanced`
- `server.js` — необязательный сервер на Node.js: `node server.js`, затем http://localhost:3000

Сайт можно просто открыть двойным кликом по `index.html`.
